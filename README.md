# Computer Graphics 2026

湘南工科大学 情報学部「コンピュータグラフィックス」の
授業資料およびサンプルプログラムを管理するリポジトリです．

## Course

- 科目名：コンピュータグラフィックス
- English: Computer Graphics
- 対象：情報学部 情報学科 2年次
- 授業形態：講義・実習
- 使用環境：Processing

## Overview

Processingを用いたプログラミングを通して，
コンピュータグラフィックスの基礎概念と実装方法を学習します．

主に以下の内容を扱います．

- 2D図形描画
- カラー表現
- アニメーション
- 座標変換
- 3Dモデル
- 陰影・照明
- ベクトル
- 物理モデル
- 再帰
- 数学アート
- Generative Art
