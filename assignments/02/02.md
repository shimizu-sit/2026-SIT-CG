# 第2回課題：基本図形と色による静止画制作

## 1．課題の目的

Processingの基本図形と色指定を用いて，1枚の静止画を制作してください．

この課題では，以下の内容を確認します．

- Processingの基本操作を理解しているか
- Processing座標系を理解して図形を配置できるか
- `point()`，`line()`，`rect()`，`ellipse()` などの基本図形を使えるか
- `background()`，`stroke()`，`fill()` を使って色を指定できるか
- 図形の描画順序によって見え方が変わることを理解しているか
- Alpha値を用いて透明度を表現できるか

Processingでは，画面左上を原点とし，右方向が `+x`，下方向が `+y` になります．この座標系を意識して図形を配置してください．

## 2．課題内容

Processingを用いて，**基本図形だけで構成されたオリジナルの静止画**を制作してください．

テーマは自由です．  
ただし，写真や画像ファイルは使用せず，Processingの描画命令だけで表現してください．

### 制作テーマ例

- 抽象的なポスター
- 幾何学模様
- ロゴ風のグラフィック
- キャラクタや顔
- 建物や風景
- 宇宙，都市，海，山などの簡単なシーン

## 3．実装条件

以下の条件をすべて満たしてください．

### 必須条件

1. 画面サイズを `size()` で指定すること  
   - 推奨：`size(600, 600);`
2. 以下の基本図形をすべて使用すること  
   - `point(x, y);`
   - `line(x1, y1, x2, y2);`
   - `rect(x, y, w, h);`
   - `ellipse(x, y, w, h);`
3. 図形を**合計10個以上**描画すること
4. `background()` を用いて背景色を設定すること
5. `stroke()` と `fill()` を用いて，線の色と塗りの色を指定すること
6. RGB値を用いて，3色以上を使うこと
7. 透明度を指定した図形を1つ以上含めること  
   - 例：`fill(255, 0, 0, 120);`
8. 図形が重なっている部分を1か所以上作ること
9. 描画順序によって見え方が変わる箇所を作ること
10. コード内にコメントを書き，どの部分が何を描いているか説明すること

## 4．使用してよい命令

今回の課題では，原則として第2回授業で扱った範囲の命令を使用してください．

```processing
size();
background();

point();
line();
rect();
ellipse();
triangle();
quad();

stroke();
fill();
noStroke();
noFill();
```

色指定には，以下の形式を使用できます．

```processing
background(r, g, b);
stroke(r, g, b);
fill(r, g, b);
fill(r, g, b, a);
```

## 5．注意事項

- 今回は静止画の課題です．アニメーションにする必要はありません．
- `for` 文，`if` 文，乱数，変数は使用しても構いませんが，必須ではありません．
- ただし，第2回の課題としては，まず座標，図形，色の指定を正確に扱うことを重視します．
- インターネット上のコードをそのままコピーして提出しないでください．
- 画像ファイルの読み込みは禁止します．
- 公序良俗に反する表現は避けてください．

## 7．発展課題

余裕がある人は，以下にも取り組んでください．

### 発展1：三角形・四角形の利用

`triangle()` または `quad()` を使って，図形表現を増やしてください．  
三角形は3つの頂点，四角形は4つの頂点を指定して描画します．

### 発展2：透明度を用いた混色表現

半透明の図形を複数重ねて，色が混ざって見える表現を作ってください．  
赤，緑，青の半透明円を重ねると，RGB加法混色とAlpha Blendingの違いを観察できます．

### 発展3：HSB色空間の利用

`colorMode(HSB, 360, 100, 100);` を使い，Hueの値を変えて色相の違いを表現してください．  
HSBは，Hue，Saturation，Brightnessによって色を指定する方法です．
