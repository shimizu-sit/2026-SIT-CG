# 第5回課題：座標変換を用いたオリジナルアニメーション

## 1．課題の目的

Processingの座標変換を利用して，**複数の図形が移動・回転・拡大縮小するオリジナルアニメーション**を制作してください．

この課題では，以下の内容を確認します．

- 図形の座標値を直接変更する方法と，座標系を変換する方法の違いを理解している
- `translate()` を使って座標系を移動できる
- `rotate()` を使って座標系を回転できる
- `scale()` を使って座標系を拡大・縮小できる
- 角度をFrameごとに更新して回転アニメーションを作れる
- `pushMatrix()` / `popMatrix()` を使って，複数の図形を独立して変換できる

## 2．課題内容

Processingを用いて，**座標変換を利用したオリジナルアニメーション**を制作してください．

テーマは自由です．

例えば，

- 複数の図形が異なる速度で回転する作品
- 惑星と衛星のような動き
- 歯車のように複数の図形が回転する表現
- 花びらや模様が中心の周囲を回転する表現
- 複数の物体がそれぞれ異なる位置を中心に回転する作品
- 回転と拡大縮小を組み合わせた抽象アニメーション
- 時計や機械のような動き

などが考えられます．

授業資料やサンプルSketchをそのまま提出するのではなく，**図形，配置，大きさ，色，回転速度，回転方向，変換方法などを変更し，自分の作品として制作してください．**

## 3．必須条件

以下の条件を**すべて満たしてください**．

1. `setup()` と `draw()` を使用すること
2. 2つ以上の図形，または図形のまとまりを描画すること
3. `translate()` を使用すること
4. `rotate()` を使用すること
5. 回転角度を変数で管理し，Frameごとに更新すること
6. `scale()` を使用すること
7. `pushMatrix()` / `popMatrix()` を2組以上使用し，複数の図形を独立して座標変換すること
8. 2つ以上の図形について，回転速度，回転方向，回転中心，拡大率，位置などのいずれかを異ならせること
9. 色を使用すること
10. 主な座標変換や状態更新について，コード内にコメントを書くこと

### 注意

- 必須の座標変換は，**実行結果に変化が確認できるように使用してください**．
- `translate(0, 0)` や `scale(1.0)` のように，見た目に変化が生じない使用だけでは必須条件を満たしたものとはしません．
- 座標変換は適用する順序によって結果が変わります．意図した動きになっているか，実行結果を確認してください．
- 実装方法については，第5回授業資料およびサンプルSketchを参照してください．
- 授業資料やサンプルSketchをそのまま提出することは認めません．

## 4．発展課題

余裕がある人は，以下にも取り組んでください．

### 発展1：変換の順序を利用する

`translate()` と `rotate()` の順序によって動きが変化することを利用し，作品の表現に取り入れてください．

例えば，

```processing
rotate(angle);
translate(100, 0);
```

のように座標変換を組み合わせると，図形を中心の周囲で回転させるような動きを作ることができます．

### 発展2：拡大縮小をアニメーションさせる

`scale()` の倍率を時間によって変化させ，図形を拡大・縮小させてください．

例えば，

```processing
float s = 1.0 + 0.3 * sin(frameCount * 0.05);
scale(s);
```

のような方法があります．

### 発展3：3つ以上の図形を独立して動かす

`pushMatrix()` / `popMatrix()` を複数使用し，3つ以上の図形をそれぞれ異なる方法で変換してください．

例えば，

- 1つ目は時計回り
- 2つ目は反時計回り
- 3つ目は回転しながら拡大・縮小

といった動きを組み合わせることができます．

### 発展4：階層的な動きを作る

座標変換を組み合わせて，

- 太陽の周囲を惑星が回る
- 惑星の周囲を衛星が回る

といった，**複数の回転中心を持つ動き**を実装してみてください．

`pushMatrix()` / `popMatrix()` と座標変換をどのように組み合わせれば実現できるかを考えてください．
