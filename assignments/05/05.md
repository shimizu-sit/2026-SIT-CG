# 第5回課題：座標変換を用いたオリジナルアニメーション

## 1．課題の目的

Processingの座標変換を利用して，**複数の図形が移動・回転・拡大縮小するオリジナルアニメーション**を制作してください．

この課題では，以下の内容を確認します．

- 図形の座標値を直接変更する方法と，座標系を変換する方法の違いを理解している
- `translate()` を使って座標系を移動できる
- `rotate()` を使って座標系を回転できる
- `scale()` を使って座標系を拡大・縮小できる
- 角度をFrameごとに更新して回転アニメーションを作れる
- `pushMatrix()` / `popMatrix()` を使って，複数の図形を独立して変換できる

第5回では，図形そのものの座標を変更するだけでなく，**図形を描く座標系そのものを変換する**方法を学びました．

この考え方を利用して，複数の図形がそれぞれ異なる動きをするアニメーションを制作してください．

## 3．必須条件

以下の条件を**すべて満たしてください**．

### 3-1．`setup()` と `draw()` を使用する

アニメーションを制作するため，`setup()` と `draw()` を使用してください．

```processing
void setup() {
  size(600, 600);
}

void draw() {
  // 描画処理
}
```

---

### 3-2．2つ以上の図形を描画する

画面内に，**2つ以上の図形または図形のまとまり**を描いてください．

例えば，

- 2つの四角形
- 円と四角形
- 複数の図形から構成した物体を2つ
- 同じ形を異なる位置に配置したもの

などで構いません．

---

### 3-3．`translate()` を使用する

少なくとも1回以上，`translate()` を使って座標系を移動してください．

例：

```processing
translate(width / 2, height / 2);
```

`translate()` によって，図形を描く基準となる原点を変更できます．

---

### 3-4．`rotate()` を使用する

少なくとも1つの図形を，`rotate()` を使って回転させてください．

例：

```processing
rotate(angle);
```

Processingでは，回転角度をラジアンで指定します．

必要に応じて，

```processing
radians(30)
```

のように `radians()` を使用できます．

---

### 3-5．回転角度を時間によって変化させる

回転角度を表す変数を用意し，Frameごとに値を更新してください．

例：

```processing
float angle = 0;
float omega = radians(2);
```

`draw()` 内で，

```processing
angle += omega;
```

のように更新します．

授業では，角度の更新を

\[
\theta_{n+1}=\theta_n+\omega
\]

と表しました．

ここで，

- \(\theta_n\)：現在の回転角度
- \(\omega\)：1 Frameあたりの角度の変化量

を表します．

---

### 3-6．`scale()` を使用する

少なくとも1つの図形に対して，`scale()` を使用してください．

例：

```processing
scale(1.5);
```

または，

```processing
scale(1.5, 0.75);
```

のように，x方向とy方向で異なる倍率を指定しても構いません．

倍率は固定値でも，時間によって変化させても構いません．

---

### 3-7．`pushMatrix()` / `popMatrix()` を使用する

複数の図形に対する座標変換が互いに影響しないように，`pushMatrix()` / `popMatrix()` を使用してください．

基本形は次のようになります．

```processing
pushMatrix();

translate(...);
rotate(...);
scale(...);

// 図形を描画

popMatrix();
```

少なくとも**2組以上**の `pushMatrix()` / `popMatrix()` を使い，2つ以上の図形を独立して変換してください．

---

### 3-8．2つの図形で異なる変換を行う

2つ以上の図形について，まったく同じ動きではなく，何らかの違いを作ってください．

例えば，

- 回転速度を変える
- 回転方向を変える
- 回転中心を変える
- 拡大率を変える
- 図形の位置を変える

などです．

例えば，

```processing
rotate(angle);
```

と，

```processing
rotate(-angle * 2);
```

のように異なる回転を設定できます．

---

### 3-9．色を使用する

以下の命令を適切に利用し，作品に色を付けてください．

```processing
background();
fill();
stroke();
noStroke();
```

すべてを使用する必要はありません．

---

### 3-10．コードにコメントを書く

主な座標変換や状態更新についてコメントを書いてください．

例：

```processing
// 1つ目の図形の座標系を保存
pushMatrix();

// 画面中央へ原点を移動
translate(width / 2, height / 2);

// 図形を回転
rotate(angle);

rect(0, 0, 100, 100);

// 座標系を元に戻す
popMatrix();
```

## 4．推奨する基本構造

以下はプログラム構造の例です．

そのまま提出するのではなく，図形，位置，色，速度，変換方法などを変更してください．

```processing
float angle1 = 0;
float angle2 = 0;

void setup() {
  size(600, 600);
  rectMode(CENTER);
}

void draw() {
  background(240);

  // 1つ目の図形
  pushMatrix();

  translate(width / 3, height / 2);
  rotate(angle1);

  fill(255, 100, 100);
  rect(0, 0, 100, 100);

  popMatrix();

  // 2つ目の図形
  pushMatrix();

  translate(width * 2 / 3, height / 2);
  rotate(angle2);
  scale(1.2);

  fill(100, 150, 255);
  rect(0, 0, 100, 100);

  popMatrix();

  // 角度を更新
  angle1 += radians(1);
  angle2 -= radians(2);
}
```

このプログラムは，課題の考え方を示すための例です．

**このコードをそのまま提出してはいけません．**

- 回転方向
- 拡大率
- 色
- 図形の組み合わせ

などを変更してください．

## 5．座標変換を考えるときのポイント

座標変換では，図形を

> どの座標に描くか

だけではなく，

> **どの座標系の中で描くか**

を考えることが重要です．

基本的には，

```text
pushMatrix()
    ↓
translate()
    ↓
rotate()
    ↓
scale()
    ↓
図形を描画
    ↓
popMatrix()
```

という流れを意識してください．

また，座標変換は順序によって結果が変わります．

例えば，

```processing
translate(100, 0);
rotate(angle);
```

と，

```processing
rotate(angle);
translate(100, 0);
```

では，図形の動きが異なります．

## 6．発展課題

余裕がある人は，以下にも取り組んでください．

### 発展1：変換の順序を利用する

`translate()` と `rotate()` の順序を変え，動きの違いを作品に利用してください．

例えば，

```processing
rotate(angle);
translate(100, 0);
```

とすると，原点から離れた位置にある図形を回転させることで，中心の周囲を回るような動きを作ることができます．

---

### 発展2：拡大縮小をアニメーションさせる

`scale()` の倍率を時間によって変化させてください．

例えば，

```processing
float s = 1.0 + 0.3 * sin(frameCount * 0.05);
scale(s);
```

とすると，図形を周期的に拡大・縮小できます．

---

### 発展3：3つ以上の図形を独立して動かす

`pushMatrix()` / `popMatrix()` を複数使用し，3つ以上の図形をそれぞれ異なる方法で変換してください．

例えば，

- 1つ目は時計回り
- 2つ目は反時計回り
- 3つ目は回転しながら拡大・縮小

といった動きを作ることができます．

---

### 発展4：階層的な動きを作る

座標変換を組み合わせて，

- 太陽の周囲を惑星が回る
- 惑星の周囲を衛星が回る

といった，複数の回転中心を持つ動きを考えてみてください．

`pushMatrix()` / `popMatrix()` と座標変換をどのように組み合わせればよいかを考えて実装してください．
