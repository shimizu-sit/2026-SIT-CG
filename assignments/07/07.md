# 第7回課題：照明を使った3Dシーン

## 1．課題の目的

Processingの照明機能を利用して，**照明によって立体感が分かる3Dシーン**を制作してください．

この課題では，以下の内容を確認します．

- 3Dモデルへ照明を設定できる
- 光源の種類による違いを確認できる
- 光の方向または位置と陰影の関係を確認できる
- `draw()`内で照明を設定できる
- 第6回の3D描画と第7回の照明を組み合わせられる

照明関数そのものを詳しく再解説しません．実装方法については，第7回授業資料およびサンプルSketchを参照してください．

## 2．課題内容

Processingを用いて，**照明によって立体感が分かる3Dシーン**を制作してください．

テーマは自由です．第6回課題で作成した3Dシーンを基に改良しても構いません．

ただし，第6回課題へ単に`lights();`を1行追加しただけの作品は不可とします．光源の種類，方向，位置などを意識して調整し，照明による見え方の変化が分かる作品にしてください．

## 3．必須条件

以下の条件を**すべて満たしてください**．

1. 3D描画用Rendererとして，`size(..., ..., P3D);`を使用すること
2. `box()`や`sphere()`などを用いて，2つ以上の3Dモデルを配置すること
3. 照明による陰影を観察しやすくするため，`noStroke();`を使用すること
4. `ambientLight()`，`directionalLight()`，`pointLight()`から2種類以上の光源を使用すること
   - ただし，少なくとも1つは`directionalLight()`または`pointLight()`とする
   - `lights()`だけではこの条件を満たさない
5. 少なくとも1つの光源について，光の方向または光源の位置を変化させること
   - 時間による変化，`mouseX` / `mouseY`，キー入力のいずれを用いてもよい
6. 照明は`draw()`内で設定すること
7. 明るい面，暗い面，光源方向または光源位置の変化が確認できるようにすること
8. 主な処理にコード内コメントを書くこと
   - 使用している光源
   - 光の方向または位置
   - 光源を変化させている処理

### 注意と範囲

- 第6回課題で作成したP3D，座標変換，3Dモデル，アニメーションを再利用して構いません．今回の中心はモデルを複雑にすることではなく，照明による見え方の変化です．
- `directionalLight()`の最後3引数は，光が進む方向です．光源の位置ではありません．
- `pointLight()`の後半3引数は，光源の位置です．例えば，`pointLight(255, 255, 255, mouseX, mouseY, 200);`のように指定できます．
- 照明はFrameごとの描画状態です．`draw()`内で設定し，光源を変化させて陰影の変化を確認してください．
- 画面全体がほぼ同じ明るさになる設定は避け，光源の種類・方向・位置を意識してください．
- 授業資料やサンプルSketchをそのまま提出しないでください．

`spotLight()`，`lightSpecular()`，`specular()`，`shininess()`，`PShape`，`loadShape()`，OBJ，MTLは必須ではありません．

## 4．発展課題

余裕がある人は，以下にも取り組んでください．**発展課題は基本評価には含めません．**

- **発展1｜スポットライト**：`spotLight()`を使用し，位置・方向・照射範囲を調整する．
- **発展2｜材質とハイライト**：`specular()`と`shininess()`を使って，ハイライトの見え方を変える．
- **発展3｜複数の動く光源**：複数の光源の位置や方向を時間によって変化させる．
- **発展4｜第6回アニメーションとの組み合わせ**：回転・移動する3Dモデルと動く光源を組み合わせる．
