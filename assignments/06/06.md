# 第6回課題：3Dモデルを用いたオリジナルアニメーション

## 1．課題の目的

Processingの3D描画機能と座標変換を利用して，**複数の3Dモデルが動くオリジナルアニメーション**を制作してください．

この課題では，以下の内容を確認します．

- `P3D`を使って3D描画できる
- X・Y・Zの3次元座標を扱える
- `translate(x, y, z)`で3次元的にモデルを配置できる
- `rotateX()` / `rotateY()` / `rotateZ()`を利用できる
- `box()` / `sphere()`を利用できる
- 状態変数をFrameごとに更新し，3Dアニメーションを作れる
- `pushMatrix()` / `popMatrix()`を使って複数モデルを独立して変換できる

課題資料では，これらの機能を詳しく解説しません．実装方法については，第6回授業資料とサンプルSketchを参照してください．

## 2．課題内容

Processingを用いて，**複数の3Dモデルが動くオリジナルアニメーション**を制作してください．

テーマは自由です．例えば，次のような作品が考えられます．

- 複数の立方体が異なる軸で回転する作品
- 球体が奥から手前へ移動する作品
- 立方体と球体が異なる位置・速度で動く作品
- 惑星のように複数のモデルが回転する作品
- 複数の3Dモデルが異なる方向へ移動する作品
- 回転とZ方向移動を組み合わせた作品

授業資料やサンプルSketchをそのまま提出するのではなく，**図形，配置，大きさ，色，回転軸，速度，移動方向などを変更し，自分の作品として制作してください．**

## 3．必須条件

以下の条件を**すべて満たしてください**．

1. 3D描画用Rendererとして，`size(..., ..., P3D);`を使用すること
2. 2つ以上の3Dモデルを描画すること
3. `box()`と`sphere()`を，それぞれ1回以上使用すること
4. `translate(x, y, z)`で，Z座標を含む配置を行うこと
5. `rotateX()`，`rotateY()`，`rotateZ()`のうち，2種類以上を使用すること
6. 回転角度や位置などを状態変数で管理し，Frameごとに更新すること
7. 少なくとも1つのモデルを，回転またはX・Y・Z方向の移動でアニメーションさせること
8. `pushMatrix()` / `popMatrix()`を使い，少なくとも2組の座標変換を独立させること

9. 2つ以上のモデルで，位置，Z座標，回転軸，速度，方向，大きさなどを異ならせること
10. 色を使い，少なくとも2つのモデルを視覚的に区別すること
11. 座標変換，回転，状態更新などの主な処理に，コード内コメントを書くこと

### 注意と範囲

- `translate(..., ..., 0)`だけでは不十分です．奥行きの違いが現れるZ値を使用してください．
- 固定した回転角度だけでは不十分です．Frameごとに状態を更新してください．
- 座標変換の順序で結果が変わるため，実行結果を確認してください．
- 授業資料やサンプルSketchをそのまま提出せず，図形，配置，色，速度などを変更してください．実装方法は第6回授業資料とサンプルSketchを参照してください．

第7回の照明機能（`lights()`，`ambientLight()`，`directionalLight()`，`pointLight()`，`spotLight()`，`specular()`，`shininess()`）とOBJ / PShapeは必須ではありません．自主的に使用しても，基本評価には影響させません．

## 4．発展課題

余裕がある人は，以下にも取り組んでください．詳しい実装方法は授業資料を参照してください．

- **発展1｜複数軸の回転**：1つのモデルに`rotateX()`，`rotateY()`，`rotateZ()`を組み合わせる．
- **発展2｜Z方向の移動とリセット**：奥から手前へ移動させ，一定位置を超えたら奥へ戻す．
- **発展3｜3つ以上のモデル**：異なる座標変換・速度で3つ以上のモデルを動かす．
- **発展4｜階層的な3Dアニメーション**：親モデルの周囲を別のモデルが回るなど，変換を組み合わせる．

**工夫例｜`sphereDetail()`**：球体の見た目と分割の細かさを調整する．関数の使用自体は必須条件ではありません．

単に関数を呼ぶこと自体は，必須条件として評価しません．
