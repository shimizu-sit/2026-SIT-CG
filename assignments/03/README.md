# 第3回課題：繰り返しと条件分岐による図形パターン生成

## 概要

Processingを用いて，`for` 文，二重ループ，`if` 文，`dist()` を組み合わせたオリジナルの図形パターンを制作する課題です．

第3回授業では，変数とデータ型，繰り返しによる図形描画，条件分岐による図形描画，二重ループと格子構造，距離と領域による図形表現を扱います．本課題では，これらの内容を1つの作品に統合して実装できるかを確認します．

## 評価基準

本課題は **10点満点** で評価します．

|        観点        | 配点 |                           評価内容                            |
| ------------------ | ---: | ------------------------------------------------------------- |
| 変数の使用         |  1点 | 図形の位置，大きさ，色，距離などを変数で管理している          |
| `for` 文の使用     |  2点 | `for` 文を使って，図形を規則的に繰り返し描画している          |
| 二重ループの使用   |  2点 | 縦横方向に図形を配置し，格子状の構造を作っている              |
| 条件分岐の使用     |  2点 | `if`，`if-else`，`else if` により，領域ごとに処理を変えている |
| 距離による表現     |  1点 | `dist()` を使い，中心からの距離に応じて色や形を変えている     |
| 作品としての完成度 |  1点 | 画面全体にまとまりがあり，図形パターンとして成立している      |
| コメント・提出形式 |  1点 | コメントがあり，指定された形式で提出できている                |

**合計：10点**

### 評価時の確認ポイント

#### 1．変数の使用

以下のような値を変数で管理しているか確認します．

- 図形の位置
- 図形の大きさ
- 図形の色
- 格子間隔
- 距離
- 図形数

例：

```processing
int gridSize = 20;
float d = dist(x, y, width/2, height/2);
```

#### 2．`for` 文の使用

同じ図形を単純にコピーして並べるのではなく，`for` 文を用いて規則的に生成しているかを確認します．

```processing
for (int i = 0; i < 10; i++) {
  ellipse(50 + i * 50, 100, 30, 30);
}
```

#### 3．二重ループの使用

縦横方向の繰り返しを組み合わせ，格子状の図形配置を作っているかを確認します．

```processing
for (int y = 0; y < height; y += 20) {
  for (int x = 0; x < width; x += 20) {
    rect(x, y, 10, 10);
  }
}
```

#### 4．条件分岐の使用

画面上の位置や距離などの条件に応じて，色や形を変更しているかを確認します．

```processing
if (x < width / 2) {
  fill(255, 0, 0);
} else {
  fill(0, 0, 255);
}
```

#### 5．距離による表現

`dist()` を用いて，画面中心など特定の位置からの距離を計算し，その値を描画に利用しているかを確認します．

```processing
float d = dist(x, y, width/2, height/2);

if (d < 150) {
  fill(255);
} else {
  fill(80);
}
```

## 教員用メモ

### この課題で確認したいこと

この課題では，作品の高度さよりも，以下の理解を重視します．

#### `for` 文を数列として理解できているか

`for` 文によって生成される繰り返し変数を利用し，位置，大きさ，色などを規則的に変化させているかを確認します．

単に「繰り返すための構文」として使うだけではなく，数列を図形配置へ変換する考え方を理解していることが望ましいです．

#### 二重ループを格子点として理解できているか

二重ループによって，`(x, y)` の組を生成し，画面上の格子点へ図形を配置しているかを確認します．

#### `if` 文を領域分割として利用できているか

条件式を単なるプログラム上の分岐ではなく，`x < width / 2` のように，画面上の領域を定義する条件として使用できているかを確認します．

#### `dist()` を距離による領域判定として利用できているか

`dist()` によって画面中心からの距離を計算し，

```processing
if (d < 150) {
  ...
}
```

のように円形領域を判定できているかを確認します．

この部分は，後のCGにおける距離関数や領域表現につながるため，特に理解してほしい内容です．
