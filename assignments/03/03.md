# 第3回課題：繰り返しと条件分岐による図形パターン生成

## 1．課題の目的

Processingの `for` 文と `if` 文を用いて，規則的な図形パターンを生成してください．

この課題では，以下の内容を確認します．

- 変数を使って，図形の位置，大きさ，色を制御できる
- `for` 文を使って，図形を規則的に繰り返し描画できる
- 条件分岐を使って，画面上の領域ごとに処理を変えられる
- 二重ループを使って，格子状の図形配置を作れる
- `dist()` を用いて，画面中心からの距離に応じて色や形を変えられる

授業資料では，変数は位置，大きさ，色，速度，角度などを管理するために使うものとして説明されています．
また，`for` 文は単なる繰り返しではなく，位置，大きさ，色，角度を規則的に変化させるための仕組みとして扱っています．

## 2．課題内容

Processingを用いて，**繰り返しと条件分岐によって生成されるオリジナルの図形パターン**を制作してください．

テーマは自由です．  
ただし，手作業で図形を大量に書くのではなく，**for文によって図形を生成すること**を必須とします．

### 制作テーマ例

- 格子状の幾何学模様
- 中心から広がるパターン
- 距離によって色が変わる点描表現
- 画面を領域分割した抽象ポスター
- ランダムな点から浮かび上がる円形領域
- 左右，上下，中心距離で色や形が変わるパターン

## 3．実装条件

以下の条件をすべて満たしてください．

### 必須条件

1. 画面サイズを `size()` で指定すること  
   - 推奨：`size(600, 600);`
2. 変数を2種類以上使用すること  
   - 例：`int rectSize`，`float d`，`int num`，`color c` など
3. `for` 文を1つ以上使用すること
4. 二重ループを1つ以上使用すること  
5. `if` または `if-else` 文を1つ以上使用すること
6. 条件分岐によって，図形の色または形を変えること
7. `dist()` を用いて，画面中心からの距離を計算すること
8. 距離に応じて，少なくとも2種類以上の見た目に分けること  
   - 例：中心に近い図形は明るい色，遠い図形は暗い色
9. `background()`，`fill()`，`stroke()` または `noStroke()` を用いて，色や線を制御すること
10. コード内にコメントを書き，どの部分が何をしているか説明すること

授業資料では，二重ループは縦横に図形を並べるために使い，格子点を生成する方法として説明されています．
また，`dist(x1, y1, x2, y2)` は2点間のユークリッド距離を求める関数として扱われています．


## 4．推奨する作品構成

今回の課題では，次のような構成を推奨します．

```processing
size(600, 600);
background(0);
noStroke();

int gridSize = 20;

for (int y = 0; y < height; y += gridSize) {
  for (int x = 0; x < width; x += gridSize) {

    float d = dist(x, y, width/2, height/2);

    if (d < 150) {
      fill(255, 100, 100);
    } else if (d < 250) {
      fill(100, 255, 150);
    } else {
      fill(80);
    }

    ellipse(x, y, 10, 10);
  }
}
```

この例はそのまま提出してはいけません．  
自分で，図形の種類，色，間隔，条件，領域分けを変更し，オリジナルの表現にしてください．

## 5．発展条件

余裕がある人は，以下のいずれかに取り組んでください．

### 発展1：3領域以上に分ける

中心からの距離 `d` を用いて，画面を3領域以上に分けてください．

例：

```processing
if (d < 150) {
  // 中心付近
} else if (d < 250) {
  // 中間領域
} else {
  // 外側領域
}
```

授業資料の演習4でも，中心からの距離によって `d < 150`，`150 <= d < 250`，`250 <= d` の3領域に分ける課題が示されています．

### 発展2：`map()` を使う

`map()` を使って，距離を色や大きさに変換してください．  
例えば，中心から遠いほど色相や図形サイズが変わるようにします．

```processing
float h = map(d, 0, 300, 0, 360);
fill(h, 80, 100);
```

資料では，`map()` は値の範囲を線形変換する関数として説明されています．

### 発展3：ランダム性を加える

`random()` を使って，図形の位置，大きさ，色の一部にランダム性を加えてください．  
ただし，課題の主目的は繰り返しと条件分岐なので，完全にランダムなだけの作品にはしないでください．
